# Where is X

Feature → files, the first place to look (plan dev-friction-review). One row per feature: don't read the whole file,
ask `tools/where.py <term>...` (the rows that hold every term, case-insensitive; `--list` prints the features only).
Paths without a top directory are under `src/`. Keep a row up to date in the commit that moves the code; a new feature
gets its row. A feature's numbers (speeds, ranges, timings) sit in `level/gameplay_config.h`; terms in
[glossary.md](glossary.md).
